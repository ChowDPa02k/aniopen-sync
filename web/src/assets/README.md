# Site icon

https://cdn.jsdelivr.net/gh/RyanL-29/aniopen/favicon.ico

SHA-256: `8774494963ebbb4507fa3da4d0a6dbae902195a6e0cceddcfe6959fa8a3bbc44`

Vite bundles the same local file for the site logo and browser favicon. No CDN
request is needed at runtime.
